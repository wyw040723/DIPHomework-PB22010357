### 数据准备

使用 `chair` 场景数据进行实验：

- 图像目录：`data/chair/images/`

## 任务流程

### 1. COLMAP 结构光恢复

运行命令：

```bash
.venv\Scripts\python.exe mvs_with_colmap.py --data_dir data/chair
```

执行过程包括：

- 特征提取（feature_extractor）
- 特征匹配（exhaustive_matcher）
- 稀疏重建（mapper）
- 二进制模型转换为文本格式（model_converter）

### 2. 3D Gaussian Splatting

运行命令：

```bash
.venv\Scripts\python.exe train.py --colmap_dir data/chair --checkpoint_dir data/chair/checkpoints --device cpu --num_epochs 10 --debug_every 5 --debug_samples 2
```

训练过程包括：

- 从 COLMAP 输出加载 `cameras.txt`、`images.txt`、`points3D.txt`
- 使用 `GaussianModel` 初始化 3D Gaussian 参数：位置、颜色、旋转、尺度、透明度
- 使用 `GaussianRenderer` 执行 3D Gaussian 投影、2D 高斯求值与 alpha-blending
- 训练过程中保存 checkpoint 和调试图像

### 3. 验证与渲染

运行命令：

```bash
.venv\Scripts\python.exe debug_mvs_by_projecting_pts.py --data_dir data/chair
```

该脚本将 COLMAP 恢复的稀疏 3D 点投影回原始视角，生成对比图像以验证恢复结果。

## 结果分析

本次实验已实现从 COLMAP 稀疏 SfM 输出到简化 3D Gaussian Splatting 的完整流水线，但当前训练稳定性仍需改进。

- COLMAP 恢复部分运行正常，稀疏点云成功生成并投影验证通过。
- Gaussian Splatting 部分可完成前向渲染和训练流程，但训练损失出现 NaN，说明当前模型参数初始化或数值稳定性不足。
- 可能原因包括：
  - 透明度或协方差计算导致数值过大/过小
  - `GaussianRenderer` 中高斯求值和 alpha 混合未充分约束
  - 训练学习率、参数初始化量级不适合 CPU 训练
